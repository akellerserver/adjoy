# ADJOY IPTV

Yeşil, siyah ve beyaz temalı statik mağaza. Paket ve uygulama lisansı seçiminden sonra ürün, süre ve fiyat WhatsApp mesaj taslağına aktarılır. Otomatik ödeme alınmaz.

## İçerik

- IBO Player, Bob Player ve Duplex TV: yıllık 250 TL; süresiz 600 TL.
- 2019 online satış başlangıcı ve 1.500+ aktif kullanıcı bilgisi işletme sahibi tarafından sağlanmıştır. Bağımsız denetim veya müşteri değerlendirme puanı olarak sunulmaz.
- IPTV paketlerinde ortak içerik, farklı süre seçimi.
- Logo, favicon, spor/film/dizi görselleri, azaltılmış hareket desteği ve durdurulabilir kayan slogan.

## Yayınlama

Derleme gerekmiyor. Kök dizindeki index.html ve ona bağlı dosyaları statik web sunucusunda yayınlayın. Alan adı: adjoytv.com. CNAME mevcut alan adı bağlantısını korur.

GitHub Pages’in ticari kullanım sınırlarını inceleyin. Satış sitesi için ticari kullanıma uygun hosting tercih edilmelidir. GitHub deposu başka hosting hizmetlerinin kaynak deposu olarak kullanılabilir.

## Bakım

catalog.js ürün verilerini, store-model.js kartları ve WhatsApp mesajlarını yönetir. Fiyat değişimlerinde index.html içindeki ilk kartlar ve yapılandırılmış fiyat bilgileri de güncellenmelidir. Şifre veya anahtar bu depoya eklenmemelidir.

robots.txt ve sitemap.xml arama motorları için hazırdır. Üst sıra veya yapay zekâ önerisi garantisi verilmez. Search Console alan adı sahibinin hesabından yönetilir.
